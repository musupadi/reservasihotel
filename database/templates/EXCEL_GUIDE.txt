===============================================
CARA MENGGUNAKAN:
===============================================

1. BUKA FILE CSV DI EXCEL:
   - Klik kanan file CSV → Open with → Excel
   - Atau: Excel → Data → From Text/CSV

2. EDIT DATA:
   - Edit cell sesuai kebutuhan
   - JANGAN ubah header (baris pertama)
   - JANGAN hapus kolom

3. SAVE AS CSV:
   - File → Save As
   - Format: CSV UTF-8 (Comma delimited)
   - Jangan pakai "CSV (MS-DOS)"

4. IMPORT KE DATABASE:
   PowerShell:
   cd c:\Blockchain\reservasihotel\database
   .\import_csv.ps1

===============================================
TIPS EXCEL:
===============================================

AUTO-GENERATE ROOM NUMBERS:
  Di Excel, gunakan formula untuk buat nomor kamar otomatis:
  
  Cell A2: 101
  Cell A3: =A2+1
  Drag down untuk auto-increment: 101, 102, 103...
  
  Untuk lantai 2:
  Cell A12: 201
  Cell A13: =A12+1
  
FILL SERIES:
  Select cell 101 → Drag fill handle → Excel auto-complete 102, 103...

CONCATENATE untuk Meeting Rooms:
  =CONCATENATE("M-ALPHA-", ROW()-1)
  Result: M-ALPHA-1, M-ALPHA-2, M-ALPHA-3

FORMAT HARGA:
  JANGAN pakai: Rp 500.000 atau 500,000
  HARUS pakai: 500000 (angka biasa tanpa format)
  
  Tips: Format cell as "Number" with 0 decimal places

===============================================
JIKA ADA ERROR SAAT IMPORT:
===============================================

"Duplicate entry":
→ ID sudah ada, gunakan nomor lain atau script akan update

"Cannot add foreign key":
→ hotel_id atau room_type_id tidak valid
→ Import hotels dulu, baru room_types, terakhir hotel_rooms

"Data too long":  
→ Text terlalu panjang, persingkat description/amenities

"Invalid number":
→ Ada format currency atau text di kolom numeric
→ Hapus "Rp", titik, koma dari angka
